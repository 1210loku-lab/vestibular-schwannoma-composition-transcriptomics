# All-common-gene MuSiC feasibility example — archived pre-outcome plan

This bounded implementation-feasibility plan was frozen before probe outcomes. It specified one actual MuSiC 1.0.0 call on replicate 1 from each of two already-frozen scenarios, using all nonzero bulk genes (markers=NULL) with the same synthetic reference, samples, and MuSiC settings as the 40-run reserved-marker pilot. The planned maximum was two calls.

The probe was not to fit limma models, alter the reserved-marker pilot, select settings, redraw samples, or count as a formal comparison. It records runtime, warnings/errors, fraction sums, and descriptive fraction error against separately saved cell-fraction and RNA-contribution truth. A failed call is retained as a failure row.

The plan refers to the frozen pilot input manifest; it does not read an archived large RDS. This is a path-sanitized copy of the original pre-outcome plan, not a new execution, approval, or result report. The original plan text does not state a calendar date or numeric seed, so neither is added here.
